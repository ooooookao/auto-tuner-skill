# 成本追踪

本文档定义 token 消耗的估算方法和费用计算规则。

---

## 估算方法

agent 无法直接读取自身 token 使用量，采用估算方式：

### 单轮 token 估算

每轮调参的 token 消耗主要来自：
1. **参数分析**：读代码、分析结果、生成新配置 → 约 3000-5000 tokens
2. **子 agent 调用**（如有）：搜索 GitHub → 约 5000-10000 tokens
3. **结果处理**：收集指标、更新日志 → 约 2000-3000 tokens
4. **架构修改**（如有）：诊断 + 修改代码 → 约 5000-8000 tokens

### 各阶段 token 估算

| 阶段 | 预估 token 消耗 |
|------|----------------|
| Step 0（工作区确认） | ~2000 |
| Step 1（规划） | ~8000 |
| Step 2 每轮（调参+分析） | ~6000 |
| Step 3 架构回溯（含搜索） | ~15000 |
| Step 4（报告） | ~5000 |

### 总消耗公式

```
总 token ≈ Step0 + Step1 + (调参轮数 × 6000) + (架构回溯次数 × 15000) + Step4
```

## 费用计算

### 获取当前模型价格

不要硬编码模型价格（会过时）。获取方式：
1. 检查 Anthropic 官网或 API 文档的最新定价
2. 使用 `WebSearch` 搜索 "claude api pricing 2026" 获取最新价格
3. 如果无法获取，使用保守估算并在报告中注明

### 估算公式

```
预估费用 ≈ 总 token × (输入比例 × 输入单价 + 输出比例 × 输出单价) / 1,000,000
```

输入输出比例按 3:1 估算（大部分 token 是输入上下文）。
